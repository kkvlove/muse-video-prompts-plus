## 怎么用

1. 在网页版（Space）里按分类或关键词搜索，点复制。
2. 人物类、产品类提示词需要先准备参考图：人物用同一张参考图锁定长相服装，产品用产品图锁定外观、颜色、logo。
3. 把提示词粘贴进 Muse，选对应画幅（9:16 竖屏 / 16:9 横屏）与时长，生成。
4. 出问题先看负面提示词：把翻车的点加进负面提示词再跑一遍，比改正向提示词见效快。

电商类提示词里的【产品名】、尺寸、价格等是占位符，替换成自己的产品信息再用。

## 一条好提示词的结构

画幅 + 时长 → 主体（参考图锁定）→ 场景 → 光线 → 运镜 → 分镜动作（按秒写节拍）→ 风格质感 → 声音（环境音 / 台词 / 音效）→ 避免项。本库每条都按这个结构写。

## 数据格式

`prompts.json`：JSON 数组，每条一个对象：

```json
{
  "id": "MP001",
  "category": "ecommerce",
  "category_zh": "电商带货",
  "title": "短标题",
  "prompt_zh": "完整中文提示词",
  "prompt_en": "完整英文提示词",
  "negative": "负面提示词，中文逗号分隔",
  "aspect": "9:16",
  "seconds": 10,
  "needs_reference": true,
  "tags": ["开箱"]
}
```
